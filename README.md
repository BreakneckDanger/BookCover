# 🎨 KDP Coloring Book Cover Studio (8.5" x 11")

A Streamlit application designed to calculate exact Amazon KDP cover dimensions and generate 400 DPI templates/print-ready covers for 8.5" x 11" White Paper coloring books.

## Specifications Implemented
- **Base Trim:** 8.5" x 11.0"
- **Spine Factor:** 0.002252" per page (White Paper)
- **Page Rounding:** Odd page counts automatically round up to the next even number.
- **Page Limits:** 24 to 590 pages
- **Resolution:** Standardized at 400 DPI
